    Class default

    Base class for module server-side helpers.

    A helper runs in the Node process and backs a single module. Override the lifecycle hooks (init, loaded, start, stop) and socketNotificationReceived to implement module behaviour. Use sendSocketNotification and registerRoute to communicate outward.
